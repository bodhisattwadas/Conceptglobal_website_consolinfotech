# AGENTS.md
## Project: Concept Global IT Division Website

## 1. Project Summary

This project is to create the full website content strategy and execution guide for the new IT division of Concept Global. The existing company website presents Concept Global as an accounting, finance, bookkeeping, data entry, and process support company with a professional, growth-focused message built around trust, diligence, cost efficiency, and dependable delivery. The website headline "Feet on the ground. Eyes on Growth." and sections like "Our Playbook, Your Growth" show that the company already positions itself as a practical business partner rather than only a service vendor. citeturn128940view0

The new IT website content must extend that same business-first identity into technology. The IT division should not sound like a random software company. It should be presented as a business operations and technology partner that understands finance, workflows, reporting, compliance-sensitive systems, and operational scale. The current website also highlights offshore accounting experience across industries such as consumer goods, manufacturing, technology, and service sectors, which supports expansion into IT services for business operations. citeturn128940view0

The IT website should help visitors understand three things clearly:

1. Concept Global understands business operations before proposing technology.
2. Concept Global builds practical digital systems that reduce manual work and improve growth.
3. Concept Global can become a long-term technology and process partner for growing companies.

## 2. Business Context from Existing Website

The current website strongly emphasizes these themes:

- Accounting and financial process expertise
- Cost-efficient and dependable service delivery
- Data security and confidentiality
- Operational support across time zones
- Growth support for clients without full-time hiring risk
- A multifaceted team with India and US roots

These points are stated across the home page, growth section, and company introduction. The current website also explicitly mentions process automation, Microsoft product expertise, AI-based knowledge, and technology integration in leadership descriptions, which gives a valid bridge toward IT services. citeturn128940view0

This means the IT website should be framed as a natural next step:

**From accounting operations to digital operations.**

Suggested positioning line:

**We understand your business first. Then we build the right technology for it.**

## 10. Technical SEO Implementation Notes

These should be followed during design and development:

- Use one unique title and meta description per page
- Add canonical URLs
- Add Open Graph tags and Twitter cards
- Use schema markup where possible, especially Organization, Service, and FAQ schema later
- Use readable URLs
- Ensure mobile responsiveness
- Optimize page speed and images
- Use descriptive alt text on images
- Keep headings properly nested: H1, H2, H3
- Add internal links between pages and service sections
- Create XML sitemap
- Configure robots.txt correctly
- Set up Google Search Console and analytics tracking

### Basic Meta Tag Template
```html
<title>Page Title Here</title>
<meta name="description" content="Meta description here" />
<meta property="og:title" content="Open graph title here" />
<meta property="og:description" content="Open graph description here" />
<meta property="og:type" content="website" />
<meta property="og:url" content="https://conceptglobal.co.in/it/page-url/" />
<meta name="twitter:card" content="summary_large_image" />
```

## 13. Content Writing Rules for All Writers and Agents

Any writer, editor, strategist, or page builder working on this project must follow these rules:

1. Keep language simple and professional.
2. Write for business owners and decision-makers, not only technical readers.
3. Focus on value and business outcomes first.
4. Avoid empty buzzwords like revolutionary, disruptive, game-changing unless supported by context.
5. Keep the tone confident but practical.
6. Stay aligned with the company’s existing trust-based identity.
7. Use SEO keywords naturally.
8. Do not overuse technical jargon.
9. Make every page end with a clear action.
10. Maintain consistency across headings, service names, and value propositions.
